# Çevirmeden Kaçış

A high-speed mobile driving game developed and published with **Unity & C#**.

Escape police checkpoints, weave through traffic, customize your cars and compete for the highest score.

## Highlights

- 90K+ downloads on Google Play
- Official gameplay video reached **630K+ views on YouTube**
- High-speed traffic and near-miss gameplay
- Police chase and checkpoint systems
- Vehicle customization and progression
- Multiple playable vehicles
- Global leaderboard
- Performance optimization for mobile devices
- Ad monetization and in-app purchases
- Continuous updates, bug fixing and publishing
